# Logo design

Original device-themed logo generated with the built-in imagegen tool.
PNG preserves generated transparency; ICO only converts the same design to Windows icon sizes.
No logo or security badge from another vendor is used.

## Final prompt

Create a unique app icon for Send-to-device, a free utility that sends files between a person's own devices. Device theme: a friendly small desktop monitor and a smartphone, joined by one bold curved forward arrow carrying a single document. Distinctive palette: rich teal, mint and navy, a tiny white highlight. Refined simple geometric product logo, clean flat shapes with restrained soft depth, strong recognizable silhouette at 32px, balanced square composition with generous safe margins. No text, no letters, no badges, no shields, no lock, no watermark, no operating-system brand marks. Actual transparent background around the centered icon. This should be an original professional desktop application icon, not a mockup or icon sheet.
